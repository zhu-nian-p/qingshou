## 一、项目概况

青售是面向在校学生的校园二手交易平台，覆盖「注册 → 发布 → 浏览 → 下单 → 卖家确认 → 面交 → 双向确认完成 → 评价 → 置顶申请 → 管理员审核 → 举报处理」的完整闭环。

- 前端：Vite 6 + Vue 3 + Element Plus + Pinia + Vue Router + ECharts（`frontend-app`，端口 5174）
- 后端：Spring Boot 3.5.16 + Java 17 + MyBatis-Plus 3.5.18 + JWT + BCrypt（端口 8080）
- 存储：MySQL 8 + Redis 7（Docker Compose）
- 实时通知：原生 WebSocket（`/ws?token=JWT`）
- AI：DeepSeek 生成商品文案（未配置 Key 时返回本地模拟文案）
- 部署目标：2 核 4G 云服务器（不引入 Elasticsearch；图片暂存本地，后续可迁移 OSS）

## 二、功能清单

### 用户端
- 学校邮箱验证码注册 / 登录 / 忘记密码（用户名 + 邮箱 + 验证码）
- 首页搜索、分类/校区筛选、骨架屏、无限滚动、置顶商品优先
- 发布闲置：图片上传（每用户限 50 张）、AI 一键写文案、敏感词校验
- 商品详情：大图、卖家信用、评价列表、掩码联系方式（复制时取完整值）、下单、举报
- 我的：资料、信用分、我发布的（编辑/下架）、我买到的（确认完成/取消/评价）、我卖出的（同意/拒绝/确认完成）
- 置顶申请：1/7/30 天阶梯价，管理员人工审核
- 实时订单通知：卖家收到 WebSocket + 桌面通知

### 管理端
- 数据看板：总用户、今日新增、在售商品、今日发布、已完成交易流水；数字滚动动画 + ECharts 近 7 天发布趋势
- 置顶审核：通过（自动置顶并计算到期时间）/ 拒绝（填写原因）
- 举报处理：查看商品、举报人、原因、时间，一键下架或忽略
- 用户封禁 / 解封
- 管理员操作审计日志（置顶、取消置顶、封禁、解封、下架、忽略举报）
- 手动触发超时订单扫描

## 三、安全与风控成果（P0 修复）

| 风险 | 处理方案 |
|---|---|
| 邮箱可重复注册、重置密码串号 | `school_email` 唯一索引；重置必须「用户名 + 邮箱 + 验证码」 |
| 买家单方面完成交易 | 双向确认：`0 待面交 → 4 待卖家确认完成 → 1 已完成`，卖家确认后才售出商品并加信用分 |
| 联系方式被批量爬取 | 详情只返回掩码（如 `wx: xia***01`）；完整值走独立接口，60 秒最多 3 次 |
| 上传刷盘 | `file_upload` 表统计，每用户最多 50 张 |
| 订单恶意占用 | 每买家最多 3 笔进行中订单；买家可取消；待面交 3 天自动取消 |
| 管理员越权/无痕操作 | 置顶、封禁、下架等写 `admin_audit_log` |
| 敏感词硬编码 | 词库外置到 `application.yml` 的 `app.sensitive-words` |
| CORS/JWT 配置过宽 | CORS 白名单（默认 5174）；JWT 密钥只从环境变量 `JWT_SECRET` 读取 |
| 举报无处受理 | `report` 表 + 详情页举报入口 + 管理后台「举报处理」Tab |
| 移动端键盘遮挡 | 输入框聚焦自动 `scrollIntoView` + `scroll-padding-bottom` |
| 合规缺失 | 注册协议勾选、用户协议/隐私政策弹窗、全站免责声明 |

## 六、启动方式

```powershell
cd D:\campus-market
docker compose up -d          # MySQL + Redis
start-backend.cmd             # 后端 8080
start-frontend.cmd            # 前端 5174（首次自动 npm install）
```

- 后端日志：`logs\startup-*.log`
- 密钥文件：`.env.local`（`JWT_SECRET`、DeepSeek Key、邮箱授权码，已 gitignore）
- 已有数据库升级：按顺序执行 `sql/002 ~ 014`；新库直接执行 `init.sql`
